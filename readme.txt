वेबसाइट की सुरक्षा के लिए विभिन्न फीचर्स जैसे राइट क्लिक, टेक्स्ट कॉपी, इमेज डाउनलोड आदि को नियंत्रित करें।

== Description ==

सुरक्षा फीचर्स एक पावरफुल प्लगइन है जो आपकी वेबसाइट की सामग्री को सुरक्षित रखने में मदद करता है। यह निम्नलिखित सुरक्षा विकल्प प्रदान करता है:

* राइट क्लिक को डिसेबल करें
* टेक्स्ट सिलेक्शन को डिसेबल करें
* इमेज डाउनलोड को रोकें
* कीबोर्ड शॉर्टकट (Ctrl+S, Ctrl+U, Ctrl+P) को डिसेबल करें
* वॉटरमार्क जोड़ें
* F12 डेवलपर टूल्स को रोकें
* प्रिंट स्क्रीन को डिसेबल करें
* कस्टम एरर मैसेज दिखाएं

== Installation ==

1. प्लगइन को WordPress प्लगइन डायरेक्टरी में अपलोड करें
2. प्लगइन को एक्टिवेट करें
3. Settings -> सुरक्षा फीचर्स में जाकर सेटिंग्स को कॉन्फ़िगर करें

== Frequently Asked Questions ==

= क्या मैं अलग-अलग पेज के लिए अलग सेटिंग्स सेट कर सकता हूं? =

नहीं, वर्तमान में सभी सेटिंग्स पूरी साइट पर लागू होती हैं।

= क्या यह मोबाइल डिवाइस पर काम करता है? =

हाँ, यह प्लगइन मोबाइल डिवाइस पर भी काम करता है।
