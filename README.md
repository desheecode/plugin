# Content Protection Desheecode

A powerful WordPress plugin to protect your website content with various security features.

## Features

- Disable right-click
- Disable text selection
- Prevent image downloads
- Disable keyboard shortcuts (Ctrl+S, Ctrl+U, Ctrl+P)
- Add watermark to content
- Disable F12 developer tools
- Disable Print Screen
- Disable Ctrl+Shift+I
- Disable Ctrl+C (copy)
- Customizable error messages
- Configurable message styling and positioning

## Installation

1. Upload the plugin files to the `/wp-content/plugins/content-protection-desheecode` directory
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to Settings -> Content Protection Desheecode to configure the plugin

## Configuration

You can configure various security features from the plugin settings page:

1. Enable/disable specific protection features
2. Customize error messages
3. Set watermark text
4. Configure message styling (colors, position, duration)

## Requirements

- WordPress 5.0 or higher
- PHP 7.0 or higher
